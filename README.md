# 📈 MathGrapher - インタラクティブ関数グラフ描画ツール

数式とグラフのつながりを直感的に体感できる、シングルファイル構成の高校数学ビジュアライザーです。  
係数スライダーを動かすことで、一次・二次・三次関数および三角関数（sin, cos, tan）の形状変化と、頂点・切片・判別式・極値・変曲点・周期などの数学的特徴点をリアルタイムに観察・学習できます。

---

## 🌟 主な機能 (Features)

### 1. 多様な関数モデルとスライダー連動
- **一次関数 ($y = ax + b$):** 傾きと切片の変化、直線の傾き具合を直感把握
- **二次関数 ($y = ax^2 + bx + c$):** 放物線の開き具合、軸・頂点の移動、判別式 $D$ に応じた解の個数判定
- **三次関数 ($y = ax^3 + bx^2 + cx + d$):** グラフのうねり、極値、凹凸が切り替わる点対称の「変曲点」の算出
- **三角関数 ($y = a \cdot \text{trig}(bx + c) + d$):** $\sin, \cos, \tan$ の切り替え、振幅・周期・位相シフト・漸近線のリアルタイム描画

### 2. 快適な Canvas 操作
- **スムーズな移動・拡大縮小:** マウスドラッグによる平行移動（パン）やホイールによるズームに対応
- **リアルタイム座標追従:** マウスカーソル位置の $(x, y)$ 座標を常時トラッキング表示
- **視点リセット:** ワンタップで原点中心の標準スケールに復帰

### 3. モダンで快適な UI / UX
- **ライト / ダークモード両対応:** 昼夜問わず見やすい配色。設定はブラウザに自動保存
- **数値入力との双方向同期:** スライダーの直感操作だけでなく、直接の数値打ち込みにも対応
- **完全ローカル完結:** 外部サーバー通信を一切行わないため、オフラインでも軽快・安全に動作
